All four row states: indexed · scanning · can’t access · missing
  • Each row: blue folder icon, name, dimmed path, then one small status line. The two quiet icon buttons on the right are Rescan and Remove.
  • “Can’t access” is amber and clickable — it opens a short plain-language explanation with a Grant Access step. “Folder missing” stays in the list (dimmed icon) so the user can remove it or rescan after restoring it.
  • The privacy line sits above the list in a soft blue box — visible every time this pane opens, never buried in fine print.
  • “Add Folder…” opens the standard macOS folder picker.
